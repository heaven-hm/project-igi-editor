# IGI-RE Research Reference

This project uses [IGI-RE](https://github.com/neonixmoddingteam/IGI-RE) as a reverse-engineering research reference for understanding the original retail Project IGI engine.

Research areas include:

- Original engine functions and runtime behaviour.
- Menu management and game state transitions.
- File formats, resource handling and game systems.
- Function addresses, enums and internal engine structures.

**Implementation:** Project IGI Editor's C++ implementations are independently authored. IGI-RE is used as a technical reference to understand and verify original engine behaviour, not as a source of copied or translated C implementation code.

**Third-party licensing:** Any source code or components actually reused from external projects must be identified and handled under their respective licenses.
